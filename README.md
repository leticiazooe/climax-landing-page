# CLIMAX Refrigeração

Landing page institucional da CLIMAX Refrigeração para apresentação de serviços, aparelhos e contato comercial.

## Funcionalidades

- Hero com vídeo em autoplay, muted, loop e playsInline
- Catálogo de aparelhos Samsung, LG e Philco
- CTA de orçamento e consulta via WhatsApp
- Serviços de instalação, manutenção e climatização comercial
- Seções de atendimento, processo e dúvidas frequentes
- Layout responsivo com React Native Web e Motion
- Deploy preparado para Cloudflare Workers com Vinext/Vite

## Tecnologias

- React 19
- TypeScript
- React Native Web
- Motion
- Vinext
- Vite
- Cloudflare Workers
- Drizzle ORM

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
```
